- 🔧 **Tech:** MATLAB, Numerical Methods

### 2. **[Wave-Function of Hydrogen](https://github.com/poyanorouzieh/Wave-function-of-Hydrogen)**
3D visualization of hydrogen atom wave functions using **Monte Carlo sampling**
- 🔧 **Tech:** Python, Scientific Visualization
- 🎨 **Focus:** 3D rendering, quantum probability distributions

- 📈 **Focus:** Barrier penetration, quantum tunneling calculations
- ⭐ Key concepts: Schrödinger equation, matrix methods
