## Featured Projects

### [Conductors in an Electric Field](https://github.com/poyanorouzieh/Conductors-in-an-Electric-Field)

A MATLAB-based computational tool for calculating the **surface charge density of 3D conductors in external electric fields**.

The project combines geometry generation, triangular surface meshing, numerical linear algebra, and the **Boundary Element Method (BEM)** to solve for the charge distribution on conductors.

The solver supports:

* Arbitrary 3D geometries defined through implicit functions
* Automatic triangular surface meshing
* Surface charge density calculation
* Time-dependent electric fields
* External field functions
* 3D visualization of charge distributions
* Animated simulation results
* Interactive MATLAB App Designer interface

```text
MATLAB · Boundary Element Method · Numerical Linear Algebra
3D Geometry · Surface Meshing · App Designer · Scientific Visualization
```

### [1D Quantum Transmission — TMM](https://github.com/poyanorouzieh/1D-Quantum-Transmission-TMM)

A MATLAB implementation of the **Transfer Matrix Method** for calculating quantum transmission and reflection through one-dimensional potentials.

The project models quantum scattering through structures such as:

* Potential barriers
* Step potentials
* Gaussian potentials
* Multi-region potentials

The implementation also explores numerical stability and adaptive spatial discretization for complex potentials.

```text
MATLAB · Quantum Mechanics · Transfer Matrix Method
Numerical Methods · Scattering Theory · Computational Physics
```

### [QM9 GAP Predictor](https://github.com/poyanorouzieh/qm9-gap-predictor)

A machine-learning pipeline for predicting **HOMO-LUMO energy gaps** of organic molecules using the QM9 dataset.

The project investigates regression-based approaches and compares different feature representations and models.

The current implementation includes:

* Data preprocessing
* Feature engineering
* Polynomial features
* Ridge regression
* Random Forest regression
* Model evaluation
* Prediction analysis

```text
Python · NumPy · Pandas · scikit-learn · Machine Learning
Regression · Scientific Data · Quantum Chemistry
```

### [Wave Function of Hydrogen](https://github.com/poyanorouzieh/Wave-function-of-Hydrogen)

A computational visualization of **hydrogen atom wave functions** based on the analytical solutions of the Schrödinger equation.

The project converts probability densities

$$
|\psi_{nlm}(r,\theta,\phi)|^2
$$

into 3D probability clouds using **Monte Carlo rejection sampling** and interactive visualization.

```text
Python · NumPy · SciPy · PyVista
Quantum Mechanics · Monte Carlo · 3D Visualization
```

### [Spatial Epidemic Simulation](https://github.com/poyanorouzieh/Spatial-Epidemic-Simulation)

A stochastic spatial **SIR epidemic simulation** implemented using a cellular-automaton-like model.

The simulation investigates how local interactions and transmission distances affect epidemic dynamics.

It includes:

* Stochastic simulation
* Spatial interactions
* Multi-distance transmission
* Monte Carlo analysis
* Statistical visualization
* Comparison with epidemic data

```text
Python · NumPy · Matplotlib
Monte Carlo · Cellular Automata · Stochastic Simulation
```
