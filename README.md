## Featured Projects

### [Conductors in an Electric Field](https://github.com/poyanorouzieh/Conductors-in-an-Electric-Field)

MATLAB-based solver for the **surface charge distribution of 3D conductors** in external electric fields using the Boundary Element Method.

`MATLAB · BEM · Numerical Linear Algebra · 3D Meshing · App Designer`

### [1D Quantum Transmission — TMM](https://github.com/poyanorouzieh/1D-Quantum-Transmission-TMM)

Numerical solver for **quantum transmission and reflection** through arbitrary one-dimensional potentials using the Transfer Matrix Method.

`MATLAB · Quantum Mechanics · TMM · Numerical Methods`

### [QM9 GAP Predictor](https://github.com/poyanorouzieh/qm9-gap-predictor)

Machine-learning pipeline for predicting **HOMO-LUMO energy gaps** of molecules using the QM9 dataset.

`Python · scikit-learn · Pandas · Regression · Quantum Chemistry`

### [Wave Function of Hydrogen](https://github.com/poyanorouzieh/Wave-function-of-Hydrogen)

3D visualization of hydrogen atom wave functions using **Monte Carlo sampling** and probability-density calculations.

`Python · NumPy · SciPy · PyVista · Quantum Mechanics`

### [Spatial Epidemic Simulation](https://github.com/poyanorouzieh/Spatial-Epidemic-Simulation)

Stochastic spatial SIR simulation with local interactions and Monte Carlo analysis.

`Python · NumPy · Matplotlib · Monte Carlo · Stochastic Simulation`
